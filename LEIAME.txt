==========================================================================
 PONTOS VOITH – V3 (ENTREGA 3: telas + animações + edição)
==========================================================================

NOVIDADES DA V3
- Navegação inferior com 5 abas: Ponto | Dia | Mês | Painel | Ajustes,
  com transição deslizante entre as telas.
- PONTO: aviso ANTES de registrar uma 2ª entrada quando já existe uma
  entrada aguardando saída (Cancelar / Registrar mesmo assim).
- DIA: horas trabalhadas do dia, turnos (ex.: 20:00 → 03:00 (+1)) e
  registros. Toque num registro para editar/excluir. Botão "Incluir"
  para registro manual (data/hora retroativa).
  * Editado  -> selo AJUSTADO + horário original guardado.
  * Incluído -> selo RETROATIVO.
- MÊS: calendário colorido conforme as horas; ponto amarelo = turno
  incompleto; toque no dia abre a aba Dia. Resumo do mês.
- PAINEL: Hoje, Semana, Total do mês, Média/dia, Dias trabalhados,
  Turnos incompletos (números animados) + gráfico de barras (horas por
  dia) e gráfico de linha (últimos 6 meses), ambos animados.
- AJUSTES: tema, GPS liga/desliga, atalho para permissões, e-mail
  padrão (usado na Entrega 4) e informações do app.

ATENÇÃO – CHAVE DE ASSINATURA
O .zip NÃO contém o arquivo app/pontosvoith.jks. Use o que JÁ ESTÁ no
GitHub desde a V2. NÃO apague a pasta "app" do repositório antes de
subir; apenas arraste a nova por cima (o GitHub substitui os arquivos e
mantém o .jks). Assim a V3 instala POR CIMA da V2 sem perder registros.

COMO SUBIR NO GITHUB
1. Extraia o .zip.
2. Add file > Upload files > arraste as pastas "app" e ".github".
   (Se a .github não aparecer no Windows, edite o build.yml no GitHub e
   cole o conteúdo de .github/workflows/build.yml.)
3. Commit changes. Aguarde o build na aba Actions.
4. Baixe o APK em Artifacts e instale POR CIMA (não desinstale).

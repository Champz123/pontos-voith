==========================================================================
 PONTOS VOITH – V2 (ENTREGA 2: banco de dados + GPS offline + tela principal)
==========================================================================

NOVIDADES DA V2
- Botões ENTRADA e SAÍDA (você escolhe). O botão "esperado" emite ondas.
- Registro salvo no celular (SQLite), 100% offline.
- GPS capturado em segundo plano, sem bloquear o ponto (até 30 s).
  Sem sinal: o ponto é salvo com "Localização indisponível".
- Endereço por extenso preenchido automaticamente quando houver internet.
- Cartão de status: turno em andamento com contador animado, ou duração
  do último turno (turno que passa da meia-noite é contado como um só).
- Texto animado: verde = sucesso, amarelo = aviso, vermelho = erro.
- Últimos 6 registros na tela principal.
- Tema claro/escuro agora fica salvo.
- Chave de assinatura FIXA (app/pontosvoith.jks): a partir da V2, as
  próximas versões instalam POR CIMA sem perder os registros.

COMO SUBIR NO GITHUB
1. Extraia o .zip.
2. No repositório: Add file > Upload files.
3. Arraste as pastas "app" e ".github" inteiras (e "docs", opcional).
   Se o Windows ocultar a pasta .github, basta editar o build.yml no
   GitHub e colar o conteúdo do arquivo .github/workflows/build.yml.
4. Commit changes. O build roda sozinho (aba Actions).

INSTALAÇÃO (SOMENTE NESTA VEZ)
- DESINSTALE a V1 antes de instalar a V2 (a assinatura mudou).
  A V1 não guardava dados, então nada é perdido.
